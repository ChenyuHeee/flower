# flower

<div class="fl-hero" markdown>

<p class="fl-hero__tagline">Портативный long-horizon agent-фреймворк на базе Claude Agent SDK.</p>

<p class="fl-hero__sub">Не жертвуя возможностями Claude Code, превратить его в специализированного агента, которого можно унести с собой, которому можно настроить взаимодействие и который может работать несколько суток.
Агент в главном потоке только принимает решения, вся ручная работа уходит в subagent; требования сначала выясняются, потом начинается работа; сделано или не сделано — решает другая роль.
На другой машине поведение то же самое — он не читает настройки хост-машины, учётные данные приносит свои.</p>

## Установка {#装}

```bash
curl -fsSL https://chenyuheee.github.io/flower/install.sh | sh
```

Скрипт сам находит `uv` / `pipx` / `pip` и ставит команду `flower`. Нужен только Python ≥ 3.10, ни Node, ни Claude Code CLI ставить не надо. После установки `cd` в любой каталог проекта и наберите `flower`: в первый раз он спросит API key или адрес шлюза, настройка один раз сохраняется в `~/.config/flower/.env` и действует везде; если на машине уже стоит и настроен Claude Code, он просто одолжит тот токен и ничего не спросит. Полные шаги и разбор ошибок — в разделе [Установка](getting-started/install.md).

## Четыре класса отказов, которые он берёт на себя {#四类失败}

<div class="fl-grid" markdown>

<div class="fl-card" markdown>
### [Предварительное уточнение](guide/clarify.md) {#前置确认}

Боитесь, что сделают не то, что вы хотели, — до начала работы есть роль, которая только задаёт вопросы и ничего не делает, пока всё не станет ясно, и замораживает требования в документ, с чтения которого начинается каждый следующий шаг.
</div>

<div class="fl-card" markdown>
### [Страж цели](guide/goal.md) {#目标看守}

Боитесь, что он скажет «готово», хотя не готово, — по окончании каждого круга работ другая роль независимо выносит вердикт: достигнуто — идём дальше, не достигнуто — возвращаем на доработку, а если в этой среде проверить нельзя — останавливаемся и спрашиваем человека.
</div>

<div class="fl-card" markdown>
### [Непрерывность](guide/continuity.md) {#接续}

Боитесь, что через несколько часов всё упадёт и придётся начинать сначала, — наберите `flower` ещё раз в том же каталоге, и работа продолжится с прежнего места; то же самое после kill процесса и после перезагрузки машины, никаких id запоминать не надо.
</div>

<div class="fl-card" markdown>
### [Передача](guide/handoff.md) {#换代}

Боитесь, что при переполнении контекста всё схлопнется в один абзац резюме, — текущая сессия сама пишет документ передачи, который человек может прочитать и поправить, и работу подхватывает новая сессия. Без compact.

## Почему он «long-horizon» {#长程}

[Координатор](reference/glossary.md#协调者) в главном потоке содержит только решения, у него нет `Write` и `Edit` — писать код, гонять тесты, искать материалы уходит в [subagent](reference/glossary.md#subagent), проб и ошибок subagent'а попадают в **другой** transcript, а главный поток получает только отчёт не длиннее 30 строк.
В том запуске HT001 длиной 10.4 часа **94.8 % символов основного текста осели в subagent**, из 1893 рабочих вызовов инструментов в поле зрения координатора попали лишь 32.
Поэтому главный поток за 70 кругов дорос всего до 185.9K и ни разу не подвергся compact — как устроен этот слой и что представляют собой остальные три, см. [Экономика контекста](guide/context.md).

## Это реально запускалось {#真的跑过}

- **[HT001](cases/ht001.md)** — терминальная IDE с нуля. $171.62 / 10.4 часа / контекст главного потока дорос до 185.9K, на выходе 12 212 строк продуктового кода; посреди работы один раз отвалилась сеть — доработал сам.
- **[HT002](cases/ht002.md)** — поставить всё это на macOS и запустить. $38.24 / около 1 часа, первый раз со стражем цели; программа действительно запустилась, а вердикт — **не достигнуто**, вопрос вынесен человеку.

На обеих страницах написано и то, что не выдерживает критики: в HT001 агент ошибся в одной строке собственной приёмки, в HT002 `git clone && make && ./cppide` растянулось на час. Каждое число пересчитывается по `runs/manifest.json` и `sessions.db` — это исходные записи, а не реклама.

## С чего начать {#从哪读起}

- **Хочу сразу запустить** — [Быстрый старт](getting-started/quickstart.md): сначала за пару центов проверить учётные данные, потом без единой строки кода прогнать трёхшаговый процесс целиком.
- **Хочу сначала разобраться в понятиях** — [Основные понятия](getting-started/concepts.md): запуск, шаг, сессия, пять ролей — всё за пять минут.
- **Хочу подключить к своему коду** — [Python API](reference/api.md): `Runtime`, `Step`, пять фабрик ролей, сигнатуры и значения по умолчанию для 62 публичных символов.
